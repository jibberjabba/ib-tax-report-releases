# IB Tax Report — downloads

IB Tax Report turns Interactive Brokers Flex Query XML files into Australian
tax workbooks (Excel) for tax agents. It covers dividends, interest, fees, CGT
events, open positions and FX, all converted to AUD at RBA daily rates.

## Download

**[Get the latest version →](https://github.com/jibberjabba/ib-tax-report-releases/releases/latest)**

| Computer | Download | Works on |
|---|---|---|
| Mac | `IB-Tax-Report-…-mac.dmg` | macOS 10.13 High Sierra or later, Intel or Apple Silicon |
| Windows PC | `IB-Tax-Report-…-windows.zip` | Windows 10 or 11, 64-bit |
| Either | `IB-Tax-Report-…-sample-data.zip` | Made-up sample files to try the app with (optional) |

You don't need to install Python or anything else. To check it works before
setting up a client's Flex Query, run it on the sample files: see
[Try it with the sample files first](docs/install.md#try-it-with-the-sample-files-first).
